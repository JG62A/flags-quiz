# Флаги стран

Простая PWA-игра: квиз по флагам для iPad Mini. Работает в Safari, ставится на домашний экран и запускается как отдельное приложение. Без App Store, рекламы и регистрации.

## Как запустить локально

Нужен любой локальный HTTP-сервер. Открытие `index.html` как файла (`file://`) не подходит: Service Worker так не заработает.

В папке проекта:

```bash
python3 -m http.server 8080
```

Затем откройте в браузере:

[http://localhost:8080](http://localhost:8080)

На iPad в той же Wi‑Fi сети можно открыть `http://IP-компьютера:8080`.

## Как загрузить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите все файлы проекта в корень репозитория.
2. В репозитории откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` (или `master`) и папку `/ (root)`.
5. Сохраните. Через минуту игра будет доступна по адресу:

`https://<username>.github.io/<repository>/`

Если Pages включён для `username.github.io`, можно публиковать из корня этого репозитория.

Файл `.nojekyll` уже добавлен, чтобы GitHub не обрабатывал проект через Jekyll.

## Как установить игру на iPad через Safari

1. Откройте опубликованный сайт в **Safari** (не в Chrome).
2. Дождитесь загрузки страницы — так файлы попадут в офлайн-кэш.
3. Нажмите **Поделиться** (квадрат со стрелкой).
4. Выберите **На экран «Домой»**.
5. Нажмите **Добавить**.

Иконка появится на домашнем экране. Игра откроется в режиме отдельного приложения. После первого открытия она работает без интернета.

## Режимы

- **Европа** — флаги европейских стран
- **Весь мир** — Европа и другие страны

В раунде 10 вопросов. Показывается название страны и 4 флага. Кнопка 🔊 произносит название. Вопросы и флаги перемешиваются.
